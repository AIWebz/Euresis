Language model in your browser

The model downloads once, is kept by your browser, and then runs on this device's graphics chip, so nothing you type is sent anywhere. It needs a recent Chrome or Edge on a computer (WebGPU). Euresis' verification gate still decides every claim's status; the model only writes the answer.
